# Projeto Final - Django + Docker + MySQL

Aplicação desenvolvida em Django utilizando Docker, Docker Compose e MySQL, criada para o trabalho final do módulo de Administração de Sistemas e Infraestruturas.

---

# Tecnologias utilizadas

- Python 3.12
- Django 6
- MySQL 8
- Docker
- Docker Compose
- Git + GitHub
- python-decouple

---

# Funcionalidades

A aplicação possui:

- Página inicial
- Lista de posts
- Página de detalhe de cada post
- Integração com base de dados MySQL
- Configuração com variáveis de ambiente
- Ambiente Dockerizado
